## Screenshot Best Practices

### Content Guidelines:
✅ **DO:**
- Use real-looking data (actual restaurant names, realistic deals)
- Show variety (different cuisines, price points)
- Include recognizable restaurant logos
- Show clear, readable text
- Use appealing food photos
- Display realistic distances (0.2 mi, 1.5 mi, etc.)

❌ **DON'T:**
- Use Lorem Ipsum or placeholder text
- Show empty states or "No results"
- Include personal information
- Use low-quality images
- Show error messages
- Include debug info or test data

### Visual Quality:
- High resolution (1080x1920 for Android minimum)
- Good lighting/contrast
- Clean interface (no clutter)
- Proper aspect ratio
- No status bar distractions (hide if possible)
