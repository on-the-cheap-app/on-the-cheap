<product_requirements>
The On-the-Cheap application helps users find local restaurant and bar specials by city/address or GPS, supporting user accounts and saving favorites. Initial features included external API integrations (Google Places/Geocoding, Foursquare), social sharing (Text, WhatsApp), ride-sharing (Uber, Lyft), and an interactive map. Google Analytics 4 was added for tracking, followed by a robust OneSignal push notification system for updates and daily digests. The application was then converted into a Progressive Web App (PWA) with installability and offline support.

The current objective is to evolve the application into a downloadable native Android/iOS app using React Native (Expo), which led to setting up the mobile development environment. Recent user requests have highlighted two key areas:
1.  **Restaurant Images**: Displaying pictures of restaurants, bars, food trucks, or pop-ups on their respective cards, prioritizing Google Places photos.
2.  **Restaurant Owner Workflow**: Developing a system for restaurant owners to register their venues and schedule specials, with an emphasis on special scheduling to outperform competitors like . The initial focus is on a modular approach for the owner platform, starting with basic features.
